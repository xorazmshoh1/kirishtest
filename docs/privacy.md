## O'zbekcha

- **Test natijalari, ballar, xatolar va sozlamalar** faqat telefoningizda saqlanadi.
- **Savollar bazasini yangilash**: ilova vaqti-vaqti bilan serverdan (Google Firebase Storage) yangi savollar faylini yuklab oladi. Bunda shaxsiy maʼlumot yuborilmaydi; server odatdagidek IP manzilni koʻrishi mumkin.
- **Reklama**: ilova Google AdMob reklamasini koʻrsatadi. AdMob reklama identifikatori, IP manzil va taxminiy joylashuv kabi maʼlumotlarni Google siyosatiga muvofiq yigʻishi mumkin. Kerakli hududlarda rozilik soʻraladi (Google UMP), uni sozlamalardan oʻzgartirish mumkin.
- **Bildirishnomalar**: kunlik test eslatmasi faqat telefonda rejalashtiriladi, uni sozlamalardan oʻchirish mumkin.
- Akkaunt talab qilinmaydi, maʼlumotlar sotilmaydi va uchinchi shaxslarga berilmaydi.
- Ilova 13 yoshdan kichiklar uchun moʻljallanmagan.
- **Ilova rasmiy emas**: u BMBA yoki boshqa davlat idorasiga tegishli emas.

## Русский

- **Результаты тестов, баллы, ошибки и настройки** хранятся только на вашем телефоне.
- **Обновление базы вопросов**: приложение периодически загружает файл с новыми вопросами с сервера (Google Firebase Storage). Персональные данные при этом не передаются; сервер, как обычно, может видеть IP-адрес.
- **Реклама**: приложение показывает рекламу Google AdMob. AdMob может собирать рекламный идентификатор, IP-адрес и приблизительное местоположение согласно политике Google. В соответствующих регионах запрашивается согласие (Google UMP), его можно изменить в настройках.
- **Уведомления**: напоминание о ежедневном тесте планируется только на телефоне и отключается в настройках.
- Регистрация не требуется, данные не продаются и не передаются третьим лицам.
- Приложение не предназначено для детей младше 13 лет.
- **Приложение неофициальное**: оно не связано с АОЗ (BMBA) или другими государственными органами.
